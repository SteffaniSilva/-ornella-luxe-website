# 🌸 Ornella Luxe Website

🔗 **Live Website:** https://ornella-luxe-website.vercel.app/

Ornella Luxe is an elegant luxury-inspired website designed with a soft feminine aesthetic, clean layout, and modern responsive design.

This project showcases a beautiful brand-style landing page with smooth sections, elegant typography, soft colors, and a premium visual style.

---

# ✨ Features

- Elegant luxury website design
- Soft feminine color palette
- Responsive layout for mobile and desktop
- Beautiful hero section
- Stylish navigation bar
- Modern UI design
- Clean and organized sections
- High-quality visual presentation
- Simple and user-friendly interface
- Deployed with Vercel

---
